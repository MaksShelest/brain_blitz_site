# Brain Blitz

Статический сайт игры. HTML, CSS, JavaScript, локальные шрифты и изображения. Без сервера, API, платных сервисов и сборки.

## GitHub Pages

1. Скопировать **содержимое `dist`** в корень своего GitHub-репозитория. Сохранить `.nojekyll`.
2. Открыть Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
3. Дождаться публикации. Все пути относительные, поэтому сайт работает и по адресу `username.github.io/repository/`.

Для бесплатного GitHub Pages на GitHub Free использовать публичный репозиторий. Публикация на GitHub в этой версии ещё не выполнена.

## Редактирование

- `dist/puzzles.js`: список пробных головоломок, картинки, ответы и подсказки с объяснениями на двух языках.
- `dist/index.html` и `dist/en.html`: русская и английская версии; атрибуты `data-ru` / `data-en` содержат обе переведённые строки.
- `dist/styles.css`: цвета, раскладка, адаптивность.
- `dist/app.js`: проверка, переключение, подсказки и счётчик.

Введённые ответы не отправляются на сервер. Прогресс хранится только в памяти открытой страницы. Ответы доступны в коде; это нормально для пробных задач без соревнований и призов.

## Проверка

Открыть `dist/index.html` в браузере. JavaScript не использует fetch или модули и работает также через file://. На GitHub Pages достаточно обычной статической публикации.

## Обновление интерфейса

- Исходный квадрат «Диаметр» 720×720 сохранён целиком в SVG.
- Пять изображений предварительно загружаются, декодируются и остаются в DOM; переключение не меняет их URL.
- После правильного ответа «Проверить» становится «Далее», переходя к следующей нерешённой задаче.
- Вопросы под рисунками убраны. Фон изображения и поля одинаковый: #090909, без смешивания цветов.
- Навигация подсвечивает цель после завершения прокрутки. «Об игре» подсвечивает весь раздел, включая карточки.
- Основная иконка в шапке и favicon: оригинальная лампочка из RuStore. BB сохранено в футере как сокращение названия.

Проверены логика переходов, предварительная загрузка, сброс и порядок подсветки. Браузерная проверка внешнего вида в этой среде недоступна.

Порядок пробных задач: Масштаб → Грани → Круг → Диаметр → Ряд. В макете телефона версия 2.0.3. Поле ввода везде «Ваш ответ».

## Две языковые версии

Русская: `index.html`, английская: `en.html`. RU / EN в шапке переводит интерфейс без перезагрузки и сохраняет текущую задачу, введённый ответ, подсказки и решённые задачи. Адрес меняется на соответствующий HTML-файл; прямые ссылки, обновление страницы и кнопки браузера работают на GitHub Pages. Сам прогресс сбрасывается при перезагрузке. Полностью переведены подсказки, решения, метаданные, доступные подписи, правила и макет телефона. Отдельный сервер не нужен.

Проверены неверные и верные ответы, «Далее», решение всех пяти задач, сброс, смена языка в обоих направлениях и сохранение введённого ответа.

Изменения условий использования: сохранение прогресса не гарантируется; обезличенная статистика используется для анализа игровых показателей и улучшения игры; права на игру и оригинальные материалы закреплены за SKRAY. Пункты относятся к приложению. Пробная веб-версия по-прежнему не содержит встроенной аналитики. Формулировка описывает использование обезличенной статистики; она не утверждает, что рекламные SDK не обрабатывают технические идентификаторы.
